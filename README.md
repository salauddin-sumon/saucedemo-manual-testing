# SauceDemo – Manual Software Testing Project

## Project Overview

This project demonstrates manual software testing of the SauceDemo e-commerce web application.

The purpose was to practice real-world QA activities, including test planning, test scenario identification, test case design, test execution, defect reporting, and test documentation.

**Application:** https://www.saucedemo.com/

**Testing Type:** Manual Functional Testing

## Objectives

- Understand the application's main workflows.
- Design and execute manual test cases.
- Validate positive and negative scenarios.
- Identify and document potential UI issues.
- Prepare standard QA documentation.

## Application Modules Tested

- Login and Authentication
- Product Listing and Sorting
- Shopping Cart
- Checkout Information
- Checkout Overview
- Order Completion
- Navigation

## Testing Summary

## Defect Identified

**BUG-001: Login Error Message Appears Vertically Clipped**

The login error message appeared vertically clipped at multiple browser zoom levels. The issue was documented with screenshot evidence and marked as Needs Review pending confirmation against UI requirements.
