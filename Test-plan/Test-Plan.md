# Test Plan – SauceDemo

## 1. Project Overview

**Project Name:** SauceDemo Manual Testing  
**Application:** https://www.saucedemo.com/  
**Testing Type:** Manual Functional Testing  
**Testing Approach:** Black-box Testing

This project focuses on testing the main functionalities of the SauceDemo e-commerce application from an end user's perspective.

## 2. Objectives

- Verify that users can log in with valid credentials.
- Verify login and checkout form validations.
- Check product sorting functionality.
- Verify shopping cart operations.
- Test the complete checkout and order completion process.
- Identify, document, and report potential defects.

## 3. Scope of Testing

The following modules are included:

- Login
- Products and Sorting
- Shopping Cart
- Checkout Information
- Checkout Overview
- Order Completion
- Navigation

## 4. Out of Scope

The following areas are not covered in this project:

- Performance and load testing
- Security and penetration testing
- API testing
- Automated testing
- Payment gateway integration testing

## 5. Testing Approach

Testing is performed manually by interacting with the application through a web browser.

The testing process includes:

- Positive testing: verifying functionality with valid inputs.
- Negative testing: verifying behavior with invalid or missing inputs.
- Functional testing: checking whether features work as expected.
- UI observation: checking the visibility and usability of interface elements.

## 6. Test Environment

**Application:** SauceDemo  
**Environment:** Public web application  
**Testing Tool:** Web browser  
**Test Type:** Manual testing

Specific browser and operating-system versions were not recorded.

## 7. Entry Criteria

- The application is accessible.
- The required test credentials are available.
- The main application features can be accessed.

## 8. Exit Criteria

- All planned test scenarios have been executed.
- Test results have been recorded.
- Identified defects have been documented.
- A test execution summary has been prepared.

## 9. Deliverables

- Test Plan
- Test Scenarios
- Test Cases
- Bug Reports
- Test Execution Report
- Test Summary Report
- Screenshots and supporting evidence

## 10. Risks and Limitations

- The project uses a publicly available demo application.
- Application behavior may change over time.
- Some observations may require further investigation before being classified as confirmed defects.
